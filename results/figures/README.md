# Figure index

Generated by `scripts/make_report.py`. Charts under *Shipped models* and
*For comparison* are produced by ultralytics during training and copied out
of the gitignored `runs/` directory.

**The ablation runs have no charts of their own** - they were trained with
`plots=False` to save GPU time. The ablation figures above are generated
from their CSVs instead.


## Generated from result CSVs (the analysis figures)

- `ablation_imgsz.png` - Resolution ablation. Right panel shows the child ranking INVERTING once lr0 was corrected.
- `ablation_optimizer.png` - SGD / Adam / AdamW, each at its own learning rate.
- `distance_distributions.png` - Centroid vs edge distance, safe vs unsafe. Shows the classes genuinely overlap.
- `risk_fusion_confusion_test.png` - Risk classifier confusion matrix on the held-out test split.
- `per_class_hazard_test.png` - Per-class hazard mAP50 on test, sorted.
- `tune_hazard_fitness.png` - Phase 2 sweep: fitness per iteration.
- `tune_hazard_scatter.png` - Phase 2 sweep: fitness vs each hyperparameter.

## Shipped models (these are the deliverables)

- `final_child_*` - Child detector, Phase 4a, imgsz 416. THE SHIPPED CHILD MODEL.
- `baseline_hazard_*` - Hazard detector, Phase 1 baseline config, imgsz 640. THE SHIPPED HAZARD MODEL - the tuned config underperformed it, see results_and_findings.md 7.1.

## For comparison only (not shipped)

- `baseline_child_*` - Child at the Phase 1 baseline config (imgsz 640). Superseded by final_child.
- `final_hazard_tuned_*` - Hazard at the Phase 2 TUNED config. Scored 0.040 mAP50 BELOW the baseline - kept to evidence that finding.

## Chart types (the `*` suffixes above)

- `_training_curves` - loss and metric curves over epochs
- `_confusion_norm` - confusion matrix, row-normalised
- `_confusion_counts` - confusion matrix, raw counts
- `_pr_curve` - precision-recall curve
- `_p_curve` - precision vs confidence
- `_r_curve` - recall vs confidence
- `_f1_curve` - F1 vs confidence
- `_class_distribution` - dataset class counts + box size/position - shows the class imbalance
- `_label_correlogram` - label coordinate correlations
- `_qualitative_pred` - MODEL PREDICTIONS on a validation batch
- `_qualitative_truth` - GROUND TRUTH for the same batch - pair with _pred
